# Java OOP Lab Task 10 – GUI & Event Handling

This repository contains **Lab Task-10 for Object-Oriented Programming (Java)**, focusing on Java Swing GUI development, event handling, `ActionListener`, button operations, form components, and table-based interfaces.

## 📌 Lab Overview

The lab demonstrates how Java GUI components can respond to user actions through event listeners. The exercises include calculator operations, an interactive Yes/No quiz, a work-details form, and a simple CRUD-style table interface.

## 🧪 Lab Tasks

### 1. Simple Calculator

A Java Swing calculator interface with:

* First and second number input
* Add, Subtract, Multiply, and Divide buttons
* Result display using `JLabel`
* `ActionListener` for button events
* Invalid-input handling
* Division-by-zero handling

### 2. Interactive Quiz

A simple GUI quiz containing:

* A question displayed using `JLabel`
* **Yes** and **No** buttons
* `GridLayout` for arranging buttons
* Feedback displayed after clicking an answer
* `ActionListener` for handling button clicks

### 3. Work Details Form

A Java Swing form containing:

* Name
* Serial Number
* ID
* Email ID
* Level selection using `JComboBox`
* Save button

### 4. Simple CRUD Interface

A basic table-based GUI demonstrating:

* Item Name
* Category
* Item Code
* Save button
* Update button
* Delete button
* `JTable`
* `DefaultTableModel`
* `JScrollPane`
